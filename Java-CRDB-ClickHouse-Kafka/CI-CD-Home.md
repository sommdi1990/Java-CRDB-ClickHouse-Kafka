## معرفی

این بخش شامل مستندات کامل CI/CD و DevOps است که برای خودکارسازی فرآیندهای build، test و deployment استفاده می‌شود. این
سیستم‌ها برای **Docker Compose** (محیط development) و **Kubernetes** (محیط production و stage) استفاده می‌شوند.

## تکنولوژی‌های اصلی

- **GitHub Actions / GitLab CI/CD**: CI/CD pipelines
- **Jenkins**: Self-hosted CI/CD (اختیاری)
- **ArgoCD**: GitOps برای Kubernetes
- **Helm**: Package manager برای Kubernetes
- **Docker**: Containerization
- **Kubernetes**: Container orchestration
