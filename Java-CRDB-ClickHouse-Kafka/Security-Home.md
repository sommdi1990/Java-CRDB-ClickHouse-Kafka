## معرفی

این بخش شامل مستندات کامل سیستم‌های امنیتی و احراز هویت است که با استفاده از **Keycloak**، **Spring Security** و *
*Spring Boot 4.0.1** پیاده‌سازی شده‌اند.

## تکنولوژی‌های اصلی

- **Spring Boot 4.0.1**: Framework اصلی (با پشتیبانی از GraalVM Native)
- **Spring Security**: امنیت و احراز هویت
- **Keycloak**: Identity and Access Management
- **OAuth 2.0 / OpenID Connect**: استانداردهای احراز هویت
- **JWT Tokens**: Stateless authentication
