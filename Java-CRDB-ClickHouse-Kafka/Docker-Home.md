## معرفی

این بخش شامل مستندات کامل Docker و Containerization است که برای بسته‌بندی و استقرار سیستم استفاده می‌شود. این سیستم‌ها
برای **Docker Compose** (محیط development) و **Kubernetes** (محیط production و stage) استفاده می‌شوند.

## تکنولوژی‌های اصلی

- **Docker**: Containerization
- **Docker Compose**: Local orchestration (برای development)
- **Kubernetes**: Container orchestration (برای production و stage)
- **Multi-stage Builds**: بهینه‌سازی image size
- **Docker Security**: Best practices امنیتی
