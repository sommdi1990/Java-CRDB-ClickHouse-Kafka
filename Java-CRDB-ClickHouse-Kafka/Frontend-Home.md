## معرفی

این بخش شامل مستندات کامل تمام کامپوننت‌های frontend است که با استفاده از **React 18+**، **TypeScript**، **Vite** و
معماری Micro Frontends پیاده‌سازی شده‌اند.

## تکنولوژی‌های اصلی

- **React 18+**: UI framework
- **TypeScript**: Type safety
- **Vite**: Build tool و development server
- **Micro Frontends**: معماری برای توسعه مستقل ماژول‌ها
