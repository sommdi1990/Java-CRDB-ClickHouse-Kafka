# گانت‌چارت بر مبنای پروپوزال (زیرساخت + دمو ماک) – ۴ اسپرینت سه‌هفته‌ای (هر اسپرینت ۱۰۸ ساعت)

- ظرفیت: شنبه تا چهارشنبه روزی ۴ ساعت (۵ روز) + پنج‌شنبه و جمعه روزی ۸ ساعت → ۳۶ ساعت در هفته → ۱۰۸ ساعت در هر اسپرینت
  سه‌هفته‌ای.
- محدوده: زیرساخت (استقرار، پلتفرم پیام، پایگاه داده‌ها، امنیت، مانیتورینگ) + دمو ماک بک‌اند/فرانت بر اساس پروپوزال (
  Gateway، Infrastructure/Business APIهای ماک، UI ماک). یک نفر توسعه‌دهنده.
- هر اسپرینت شامل زمان مستندسازی/گزارش جداگانه است.

## وابستگی‌ها (خلاصه)

- اسپرینت ۰ باید پیش از سایر اسپرینت‌ها کامل شود.
- اسپرینت ۱ به آماده بودن سرور و ابزار پایه (اسپرینت ۰) متکی است.
- اسپرینت ۲ به CI/CD پایه و ریجیستری/زیرساخت مستقر (اسپرینت ۱) متکی است.
- اسپرینت ۳ به استقرار Kafka و جمع‌آوری متریک‌های آن (۲) و به زیرساخت CI/CD (۱) و راه‌اندازی Kubernetes (۲.۱۲–۲.۱۴) متکی
  است.
- اسپرینت ۴ (دموی ماک) پس از آماده بودن CI/CD پایه (۱) و دسترسی به سرویس‌های زیرساختی امن و مانیتور شده (۲ و ۳) شروع شود
  تا دمو قابل استقرار و قابل مشاهده باشد.

## نکات برنامه‌ریزی

- ظرفیت هر اسپرینت ۱۰۸ ساعت است (۳۶ ساعت در هفته × ۳ هفته)؛ جمع فعالیت‌ها در هر اسپرینت <= ۱۰۸ ساعت نگه داشته شده است.
- برای هر فعالیت، خروجی قابل تحویل (deployment + چک‌لیست تست + مستند) تعریف شود تا ورود به اسپرینت بعدی بدون بدهی انجام
  شود.
- مستندسازی و گزارش در انتهای هر اسپرینت به صورت جداگانه لحاظ شده تا نیاز به فاز مجزا نباشد.
