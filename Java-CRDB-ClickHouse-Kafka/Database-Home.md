## معرفی

این بخش شامل مستندات کامل تمام دیتابیس‌های استفاده شده در پروژه است:

- **CockroachDB**: دیتابیس اصلی برای ذخیره‌سازی داده‌های تراکنشی
- **ClickHouse**: دیتابیس تحلیلی برای لاگ‌ها و آمارها
- **Redis**: Cache و Buffer برای بهبود عملکرد
- **Flyway**: ابزار مدیریت migration دیتابیس برای مدیریت تغییرات schema
