## معرفی

این بخش شامل مستندات کامل Nginx و Routing است که برای load balancing، reverse proxy و SSL/TLS استفاده می‌شود.

### استفاده در پروژه

- **Docker Compose**: Nginx به عنوان reverse proxy و load balancer
- **Kubernetes**: Nginx Ingress Controller برای routing و load balancing در production و stage environments
- **SSL/TLS**: مدیریت certificateها و HTTPS
